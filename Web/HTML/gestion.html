FUNDAMENTOS DE CALIDAD

Fundamentos de calidad del software.

La calidad se relaciona con la capacidad de un producto para satisfacer necesidades mediante atributos, métricas y estándares compartidos.

Conceptos clave

Adecuación funcional, rendimiento, usabilidad, fiabilidad, seguridad y mantenibilidad ayudan a evaluar un producto.

Métricas

Las métricas aportan evidencia para evaluar, aprender y mejorar decisiones de calidad.

ISO 9126: modelo de calidad

Estándar clásico que clasifica la calidad del software en atributos internos, externos y de uso.

TÉCNICAS DE ASEGURAMIENTO

Pruebas para aprender antes de liberar.

Explorá los niveles y técnicas de prueba para conocer su definición, objetivo y ejemplo.

Verifican componentes o módulos individuales aislados del resto del sistema para asegurar su funcionamiento correcto.

Evalúan la interacción entre módulos o servicios combinados para detectar fallos en sus interfaces o contratos.

Validan el sistema completo e integrado para garantizar que cumple con los requisitos funcionales y no funcionales especificados.
